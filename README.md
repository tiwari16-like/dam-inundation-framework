# Dam Inundation Modelling Framework

## Project Status

Day 1 — Environment and project structure setup.

## Objective

Development of an automated framework for dam-break and flood-inundation scenario modelling using hydrodynamic simulation, geospatial processing, and satellite-based validation.

## Planned System

```text
Input Data
    ↓
Data Preprocessing
    ↓
Scenario Generation
    ↓
Hydrodynamic Simulation
    ↓
Result Processing
    ↓
Flood Inundation Mapping
    ↓
HADR Impact Analysis
    ↓
Visualization / Dashboard
```

## Current Technology Stack

* Python
* NumPy
* SciPy
* Pandas
* GeoPandas
* Rasterio
* Shapely
* PyProj
* Xarray

## Planned Components

* Delft3D FM hydrodynamic modelling
* Dam-break scenario generation
* GIS-based inundation analysis
* Satellite-based validation
* HADR impact assessment
* Dashboard visualization
* SPH-based model comparison as a research extension

## Current Milestone

Establish a reproducible Python environment and successfully execute the first baseline hydrodynamic simulation.
